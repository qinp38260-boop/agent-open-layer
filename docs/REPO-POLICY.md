# 仓库边界：公开库只放项目本体，真实运行只在私库

> 定于 2026-11-11。这条边界优先于任何"图省事"的做法。

## 公开库（本库，`agent-open-layer`）只允许放

| 允许 | 说明 |
|---|---|
| 源码、测试、文档、探针脚本 | 项目本体的全部内容 |
| 一次性 runner 上的**无密钥**验证 | 例如 L0 隔离验收、L2 iptables 出口封锁、`fake-host` 通道验证 |
| 合成数据 / 演示数据 | 不含任何真实业务、真实账号、真实密钥 |

## 公开库**禁止**

| 禁止 | 原因 |
|---|---|
| 任何真实密钥、token、账号口令（含作为 Actions secret） | 公开库即公开场所，secret 一旦配错或误导出即泄露 |
| 真实业务数据、真实客户信息、内网地址 | 涉密与合规 |
| 对接真实模型/真实生产环境的**运行**流水线 | 运行会产生费用、留下痕迹，且需要凭据 |

## 真实运行一律在**私库**

私库承担：
- 配 `DEEPSEEK_API_KEY` 等 secret，跑真 codex / 真模型
- 真实项目目录、真实数据的集成验证
- 与客户环境相关的验收

私库从公开库同步代码（`git subtree` / 手动 pull），但**不反向提交任何凭据**。

## 落地检查

- 公开库 workflow 里出现 `secrets.` 一律视为违规，需改为私库执行或跳过
- 公开库 `.github/workflows/*.yml` 只允许：test / l0-acceptance / l2-egress / agent-run-linux（无密钥通道验证）
- 新增流水线前先问一句：**它需要凭据吗？** 需要 → 私库
